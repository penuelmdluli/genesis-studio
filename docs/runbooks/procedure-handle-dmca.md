# Procedure: Handle DMCA Takedown Request

## When This Applies
- A copyright holder submits a DMCA takedown notice for content hosted on the platform
- Received via email, legal contact form, or hosting provider forwarding

## Steps
1. Verify the notice contains all required elements (17 U.S.C. 512(c)):
   - Identification of the copyrighted work
   - Identification of the infringing material with URL/location
   - Contact information of the complainant
   - Good faith statement and perjury declaration
   - Signature (physical or electronic)
2. If the notice is incomplete: respond requesting the missing elements within 5 business days
3. If the notice is valid:
   - Remove or disable access to the identified content within 24 hours
   - Delete the video/image from R2 storage
   - Notify the user who uploaded/generated the content via email
   - Inform them of their right to file a counter-notice
4. If a counter-notice is received:
   - Verify it contains required elements (identity, consent to jurisdiction, perjury statement)
   - Forward counter-notice to the original complainant
   - Restore content after 10-14 business days unless complainant files court action

## Verification
- Infringing content is no longer accessible via any public URL
- User has been notified with takedown details
- DMCA log updated with notice date, content ID, action taken, and resolution
